# Alberto Scalia – Personal Portfolio

This repository features the source code of my personal portfolio, built to demonstrate the synergy between **editorial precision** and **modern frontend performance**. Originally developed as a milestone project for the **start2impact** HTML & CSS course, it has evolved into a sophisticated React application.

## 🚀 Technical Stack & Features

The project is engineered for speed and maintainability, reflected in the codebase composition:

* **React**: Powers the core architecture, ensuring a reactive and component-driven user experience.
* **Tailwind CSS**: Utility-first styling for rapid layout iteration, responsive design, and precise typography control.
* **Framer Motion**: Smooth, declarative entrance animations and interactive micro-interactions.
* **Phosphor Icons**: Integrated vector icon library (`@phosphor-icons/react`) for crisp visual cues.
* **SEO & Semantic HTML**: Structured to ensure maximum discoverability and accessibility.
* **Automated Deployment**: Integrated with **GitHub Pages** for seamless CI/CD and instant updates.
* **Performance Optimized**: Minimized assets and clean code practices for rapid load times.

## 🎨 Design Philosophy: Visual Synthesis

As a UI Designer with a strong background in Editorial Design, I designed this interface to focus on **conversion through clarity**:

1. **High-Contrast UI**: A deep black foundation paired with strategic accent colors to direct user attention.
2. **Typographic Dominance**: Elegant serif and bold sans-serif pairings used to establish an immediate professional hierarchy.
3. **Efficiency**: A distraction-free UX designed to lead visitors straight to the work that matters.
